# Salamander Grand Piano samples

The piano samples in this directory are derived from the **Salamander Grand
Piano V3** by **Alexander Holm**.

- Source project: <https://github.com/sfzinstruments/SalamanderGrandPiano>
- Sample files used for this build: <https://tonejs.github.io/audio/salamander/>
- License: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
- License text: <https://creativecommons.org/licenses/by/3.0/>

The files were converted to mono (left channel), 32 kHz OGG Vorbis, trimmed to
about five seconds, and given a short fade-out. No other pitch or content
changes were made. The engine pitch-shifts the nearest sampled root by no more
than two semitones.

Attribution is also included in the project README and LICENSE.
